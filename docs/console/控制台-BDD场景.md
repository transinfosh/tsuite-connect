# Connect 控制台 BDD 场景

| 编号 | 场景 | 预期行为 |
| --- | --- | --- |
| LOGIN-01 | 用户登录后第二天返回 | 登录仍有效；第 7 天边界失效，不无限续期 |
| LOGIN-02 | 管理员设置自定义登录有效期 | 数据库与 Cookie 一致；拒绝非整数、少于 8 小时或超过 30 天 |
| LOGIN-03 | 本地用户密码正确并通过 TOTP | 同一页面完成验证，challenge 一次消费，登录 Cookie 保留安全属性 |
| LOGIN-04 | 用户退出、被禁用或完成 TOTP 重绑 | 原网页会话失效；后续 API 明确要求重新登录 |
| LOGIN-05 | GitHub 账号无组织/团队资格，或 API 返回 403/404 | 明确配置的组织/团队以及接受邀请、read:org、OAuth 批准建议；不笼统称服务不可用 |
| LOGIN-06 | 匿名用户打开首页 | 可见 GitHub 准入要求；页面返回 401，服务健康检查保持兼容 |
| SPA-01 | 查看列表、详情、创建和切换两端系统 | 使用 React 导航，不整页刷新；客户与支持机系统独立 |
| SPA-02 | 直接打开或刷新详情地址 | 返回 SPA，再读取详情，不重新发放一次性命令 |
| SPA-03 | 手机或减少动画偏好的用户访问 | 无页面水平溢出；会话操作可见；减少动画设置生效 |
| SESSION-01 | 创建会话，客户尚未接入 | 默认 Linux，两端命令和 AI 说明立即可用；不泄漏兼容 token |
| SESSION-02 | 已接入客户切换客户操作系统 | 后端拒绝并提示刷新状态；切换支持机系统不修改客户配置 |
| SESSION-03 | 正在操作的 SSH 连接被正常关闭 | 客户清理标记确认后撤销；标记后 SSH 255 断线不误判为失败 |
| SESSION-04 | 客户清理未确认 | 显示原因和诊断编号；不撤销连接、不删 key、不自动强制关闭；支持重试 |
| SESSION-05 | 网络或远程服务超时 | 明确结果尚未确认，要求查询状态；不自动重复创建或关闭 |
| ACCESS-01 | 未登录请求私有 API | 返回 401 JSON，前端回登录页并清理一次性命令内存 |
| ACCESS-02 | 跨域 POST、CSRF 缺失或错误 | 拒绝，不调用 broker；操作员不能管理用户 |
| ACCESS-03 | 获取详情或用户列表 | 不返回私钥、密码哈希、TOTP 密钥和一次性授权 |
| ACCESS-04 | 任意静态资源路径或服务异常含秘密 | 目录穿越被拒绝，错误不透传原始 stderr；渲染不执行客户名称中的 HTML |
| SPA-04 | 通过键盘打开并取消弹窗 | 自动聚焦首个输入，Escape 关闭后回到触发按钮；动态样式不产生 CSP 拒绝 |
| SPA-05 | 目标页面数据响应缓慢 | 点击立即切换路由和页面框架；已有目标数据立即显示并后台刷新，首次读取显示骨架；不等待响应 |
| SPA-06 | 刷新会话详情 | 原详情持续可见；请求期间显示忙碌状态 |
| SPA-07 | 切换页面或会话状态筛选 | 支持的浏览器执行短过渡；减少动画偏好关闭过渡；桌面列表保持紧凑 |
| SPA-08 | 数据加载时快速切换到其他页面/详情 | 导航仍可用，旧响应不覆盖新详情，旧请求失败不显示在新页面 |
| SESSION-06 | 切换受控机或控制机系统，另一端继续选择 | 仅当前端选择显示等待；另一端可操作；两次响应应用后双方选择与命令一致 |
| SESSION-07 | 首次系统更新失败，另一端选择已排队 | 显示错误和未提交说明，清除待处理状态；不重放排队请求 |
| SPA-09 | 查看新建命令页 | 只有受控机、控制机两步；AI 说明在控制机步骤内，仍可独立复制；手机无横向溢出 |
| SESSION-08 | 受控机已有活动连接，再执行新接入命令 | 显示旧连接 ID、名称和查找关闭指引；保留旧连接及新授权 |
| USER-01 | 管理员邀请同事并完成密码、TOTP 绑定 | 一次性邀请链接可复制；完整流程可用，完成后用户可登录 |
| INSTALL-01 | 原地升级控制台 | 缺失产物提前失败；部署复制新模块与资源；保留已有登录期限及凭据 |

真实 OAuth 授权、组织权限变化生效窗口及真实客户连接的系统验收需按实际环境核验，
不得把 fixture 场景等同于线上验收。
