## React + shadcn/ui 改版

同日按用户选择将 Vue 实现替换为 React + TypeScript，采用官方 shadcn/ui new-york
组件源码及 Radix、Lucide、Tailwind。增加状态筛选，移除侧栏、装饰性英文标题及统计卡片。
`frontend/components.json` 记录组件配置，可继续通过官方 CLI 维护。

`npm run build --prefix frontend` 包含 TypeScript 检查。Python 新增 HTML 样式 nonce
独立性检查；浏览器增加受控弹窗焦点归还、Escape 及 CSP 检查。桌面/手机使用合成数据
核验，真实 GitHub、物理手机和客户机器验证边界不变。

## 紧凑布局与过渡

移除手写布局及配色 CSS，使用官方 Neutral 主题、Card/Tabs/Table/NavigationMenu 和标准
Tailwind 工具类。仅为页面过渡和系统减少动画偏好保留少量动画规则。导航立即切换页面，列表使用当前登录内存中的数据并后台刷新；首次读取显示骨架。
详情刷新保留内容，快速导航时忽略旧请求响应。Chromium 验证实际动画、慢请求、减少动画及布局密度；
不支持 View Transitions 的浏览器退回普通导航，Firefox、Safari 和物理手机未实机验收。

## 即时导航修正（v0.3.2）

v0.3.1 为避免闪动而等待目标请求完成，导致切换停顿。现改为立即提交路由、异步加载，
读请求与变更操作锁分离。回归使用未释放的请求屏障验证响应前已切换，并覆盖旧响应隔离。
未更改后端、数据库、权限、Cookie 或一次性授权的保存方式。

## 两端选择和两步骤（v0.3.3）

修复两端共用 busy 导致联动置灰。前端独立跟踪两端状态，使用最新确认的平台组合依次提交；
不改变原有接口和服务器的系统版本校验。失败停止后续请求，避免结果不明时自动重放。
命令页统一采用受控机/控制机，AI 说明归入控制机步骤，继续采用现有默认组件样式。
